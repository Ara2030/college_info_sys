# Установка ИС колледжа на компьютер

Установочный файл: **`dist\installer\CollegeIS_Setup_1.0.0.exe`** (~405 МБ).
Внутри уже есть всё необходимое: Python 3.14.7, PostgreSQL 17.11, библиотеки,
код системы и база данных с демонстрационными записями (72 студента, 13 групп).

## Требования

| Параметр | Значение |
|---|---|
| ОС | Windows 10/11, 64-бит |
| Права | администратор (установщик запросит подтверждение UAC) |
| Диск | ~2 ГБ свободно |
| ОЗУ | от 4 ГБ |
| Интернет | **не нужен** — всё в комплекте |

Если на компьютере уже стоят Python 3.10+ и/или PostgreSQL — установщик их
использует и не ставит повторно.

## Обычная установка

1. Скопируйте `CollegeIS_Setup_1.0.0.exe` на компьютер колледжа (флешка, сеть).
2. Двойной щёлчок → «Да» в запросе администратора.
3. Мастер: папка установки (по умолчанию `C:\CollegeIS`) → «Установить».
4. Откроется окно настройки: установка Python и PostgreSQL, создание базы,
   сборка окружения. Это занимает 2–7 минут (на чистой машине — дольше).
5. На последнем экране — галочка «Запустить систему сейчас». Система откроется
   в браузере по адресу `http://127.0.0.1:8000/`.

Ярлыки: рабочий стол, меню «Пуск», пункт «Удалить ИС колледжа».
Дополнительно можно включить автозапуск при входе в Windows (галочка в мастере).

## Учётные записи после установки

| Роль | Логин / пароль |
|---|---|
| Администратор | `admin` / `admin123` |
| Директор | `director` / `director123` |
| Методист | `methodist` / `methodist123` |
| Преподаватель | `teacher1` / `teacher123` |
| Студент | `student1` / `student123` |
| Родитель | `parent1` / `parent123` |

Пароли ролей БД генерируются при установке и сохраняются в
`C:\CollegeIS\logs\ДОСТУПЫ.txt`. Смените пароль `admin` после первого входа
(меню пользователя → «Сменить пароль»).

## Тихая установка (для нескольких компьютеров)

```powershell
CollegeIS_Setup_1.0.0.exe /VERYSILENT /SUPPRESSMSGBOXES /NORESTART `
  /DIR="C:\CollegeIS" /DBNAME=college_sys /APPROLE=college_app `
  /LOG="C:\CollegeIS\setup.log"
```

Параметры `/DBNAME` и `/APPROLE` необязательны — нужны, если на компьютере уже
есть база с таким именем и её нельзя перезаписывать. Код возврата 0 — успех.

## Что и куда устанавливается

| Компонент | Расположение |
|---|---|
| Код системы | `C:\CollegeIS` |
| Виртуальное окружение Python | `C:\CollegeIS\.venv` |
| Параметры (пароли, секретный ключ) | `C:\CollegeIS\.env` |
| Журнал установки и пароли | `C:\CollegeIS\logs\` |
| PostgreSQL 17 | `C:\Program Files\PostgreSQL\17`, служба `postgresql-x64-17`, порт 5432 |
| Python 3.14 | `C:\Program Files\Python314` |
| База данных | `college_sys`, роль приложения `college_app` |

Роль `college_app` не является суперпользователем: только чтение и изменение
данных, без изменения структуры БД (защита по требованию к ИБ в дипломе).

## Запуск и остановка

- Ярлык «Информационная система колледжа» → `start.bat` → `scripts\start.ps1`.
  Скрипт сам проверяет окружение, поднимает PostgreSQL, применяет миграции,
  запускает сервер и открывает браузер. Свободный порт подбирается автоматически,
  если 8000 занят.
- Остановка: `Ctrl+C` в окне консоли.
- Если что-то сломалось (например, удалили Python), `start.bat` обнаружит это и
  восстановит окружение из локального комплекта библиотек — интернет не нужен.

## Удаление

«Параметры» → «Приложения» → «Информационная система колледжа» → «Удалить»
(или ярлык «Удалить ИС колледжа» в меню «Пуск»).

Удаляются программа, окружение и ярлыки. **База данных сохраняется** — чтобы
удалить её, выполните в pgAdmin/psql:

```sql
DROP DATABASE college_sys;
DROP ROLE college_app;
```

## Если установка не завершилась

1. Откройте `C:\CollegeIS\logs\install.log` — последние строки содержат причину.
2. Типичные случаи:
   - «Не удалось подключиться к PostgreSQL как postgres» — на компьютере уже
     есть PostgreSQL с другим паролем администратора. Запустите установщик
     повторно, указав пароль: `install_system.ps1 -PgAdminPassword "пароль"`.
   - Порт 5432 занят другой программой — остановите её или укажите порт в
     `postgresql.conf`.
   - Антивирус блокирует установку — добавьте установщик в исключения.
3. Повторный запуск установщика безопасен: уже установленные компоненты
   пропускаются, данные базы не перезаписываются.

## Пересборка установщика (для разработчика)

```powershell
# 1. Один раз запустить систему, чтобы появился .venv
start.bat

# 2. Собрать установщик (свежий дамп БД + библиотеки + компиляция)
powershell -ExecutionPolicy Bypass -File installer\build_installer.ps1
```

Результат: `dist\installer\CollegeIS_Setup_<версия>.exe`.
Скрипт сборки: копирует код (без `.venv`, `.env`, `.git`), делает `pg_dump`,
скачивает колёса `pip` и дистрибутивы Python/PostgreSQL в `installer\cache`
(повторно не скачивает), компилирует `.iss` через Inno Setup.

Состав установщика: `installer\college_is.iss` (мастер), `installer\payload\install_system.ps1`
(настройка на целевой машине), `installer\assets\app.ico` (иконка).
